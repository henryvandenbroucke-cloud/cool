# Calculator

A plain, simple calculator. Nothing else.

- `+` `−` `×` `÷`, `%`, `±`, decimal point
- `AC` clear, `⌫` backspace
- Keyboard: numbers, `+ - * /`, `Enter` = equals, `Esc` = clear, `Backspace`
- No dependencies, no build step — everything is in `index.html`

## Run it

```bash
npm start
# → http://localhost:4173
```

Or just open `index.html` in a browser.

## Files

```
index.html   The calculator (HTML + CSS + JS in one file)
server.mjs   Tiny static server for `npm start`
```
